# Memento Mori

### *"Recuerda que morirás"*

Una aplicación gratuita y de código abierto para visualizar las semanas de tu vida.

Porque el tiempo es el recurso más valioso que tenemos, y no deberíamos olvidarlo.

## La Filosofía

**Memento Mori** es una antigua práctica filosófica de reflexión sobre la mortalidad. Los estoicos la usaban para vivir con mayor intención, los monjes medievales la recordaban en sus oraciones, y artistas del Renacimiento la plasmaban en sus obras.

No es un pensamiento morboso. Es un **recordatorio de que cada semana cuenta**.

> *"No es que tengamos poco tiempo, sino que perdemos mucho."*
> — Séneca

## ¿Qué hace esta app?

Visualiza tu vida en semanas. Si vives hasta los 80 años, tendrás aproximadamente **4,160 semanas**. Esta app te muestra:

- Cuántas semanas has vivido
- Cuántas te quedan (estadísticamente)
- Un recordatorio semanal para reflexionar

## Propósito

Este proyecto es **completamente gratuito y sin ánimo de lucro**.

- **Sin anuncios** — Tu atención es tuya
- **Sin tracking** — Tu privacidad es sagrada
- **Sin suscripciones** — El tiempo no debería tener paywall
- **Código abierto** — Transparencia total

Creemos que herramientas para el bienestar mental y la reflexión personal deberían ser accesibles para todos, sin importar su situación económica.

## Características

- **Visualización de vida** — Ve tu vida en perspectiva con una cuadrícula de semanas
- **Recordatorios semanales** — Notificaciones configurables para reflexionar
- **PWA instalable** — Funciona offline y se instala como app nativa
- **Privacidad total** — Todos los datos se guardan localmente en tu dispositivo
- **Diseño minimalista** — Sin distracciones, solo lo esencial

## Instalación

### Como usuario

1. Visita la app en tu navegador
2. En móvil: "Añadir a pantalla de inicio"
3. En escritorio: Icono de instalación en la barra de direcciones

### Como desarrollador

```bash
# Clonar el repositorio
git clone https://github.com/VanguardiaAI/Memento-Mori.git

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build
```
